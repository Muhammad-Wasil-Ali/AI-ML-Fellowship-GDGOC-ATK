Mobile Calculator
A simple calculator app built with Python and Streamlit.
Features

Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
Decimal number support
Clear (C) and Backspace (⌫) functionality
Division by zero error handling
Clean and simple UI

Setup:

1. Clone the prject
   git clone

2. create a virtua environment
   python -m venv mini_project

3. Activate the virtual environment
   For windows : mini_project/Scripts/activate
   For Mac/Linux : source venv/bin/activate

4. Insatll the require dependecies
   pip install -r requirementstxt

5. RUn the app
   streamlit run mini_project/src/app.py
